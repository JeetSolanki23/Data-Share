    How it works

    Built for real file-sharing workflows.

    Stage before you send

    Add as many files as you need, review the full set, then upload in one go. Nothing gets sent until you confirm.

    Quota you can see

    The storage meter reflects actual backend limits in real time. When no cap is set, it shows unlimited.

    No duplicate storage

    File hashes are checked before each upload. If an identical file already exists, it gets skipped rather than stored twice.

    Opaque share links

    Share URLs use a token, not the raw filename. Recipients get a clean link; the actual path stays private.
